## 🌟 Overview

This project is a high-impact, production-ready enhancement to **Cynbit Technologies' official website**. After analyzing `https://cynbit.in` from both user and developer perspectives, we engineered **Cynbit Studio v2.0** to transform the company's online presence from a static corporate brochure into an interactive demonstration of its core technical mastery.

### 🚀 Key Features Implemented

1. **Autonomous AI Architecture Studio & Dynamic ROI Engine:**
   - Interactive domain selector (E-Commerce, FinTech, Healthcare, EdTech).
   - Real-time animated multi-agent pipeline (Supervisor Router, API Tool Agent, RAG Vector Search, Human-in-the-Loop Escrow).
   - Dynamic mathematical formula calculating annual cost savings (₹ Lakhs), hours reclaimed, and latency compression based on interactive slider inputs.
   - One-click copy/download of architecture specification JSON with confetti celebration.

2. **BitElevate Engineering Workbench & PR Review Simulator:**
   - Lets prospective interns experience BitElevate's unique workflow before enrolling.
   - Interactive GitHub PR diff viewer with simulated senior mentor feedback from Director Mohak Saini.
   - One-click PR fix, review approval, merge, and verified credential generation.
   - Highlights 14-day Semester Exam Freeze, flexible asynchronous hours, and university credit approval.

3. **Cynbit Copilot (Autonomous Floating Agent):**
   - Floating assistant in the bottom-right corner trained on Cynbit's corporate profile, BitElevate pricing (₹3,999), office location in Jaipur, and technical services.
   - Context-aware quick prompt chips and lead routing.

4. **Comprehensive About & Social Impact Portal (Fixes 404 Route):**
   - Solves the broken `/about` 404 link on current `cynbit.in`.
   - Showcases Cynbit's corporate identity (CIN: `U62011RJ2024PTC093652`), leadership team (Ashutosh Upadhyay, Mohak Saini, Dhawan Kumar Nama), and philanthropic partnership with **Manav Seva Trust**.

5. **Integrated Technical Assessment Report:**
   - Full Markdown and in-app interactive document detailing the problem statement, technical stack choices, implementation, and results.
